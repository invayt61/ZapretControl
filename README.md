# Zapret Control

<img src="Windows/Assets/app.png" width="128" height="128" alt="Zapret Control" />

Неофициальный графический интерфейс Windows для [zapret-discord-youtube](https://github.com/Flowseal/zapret-discord-youtube) и [TG WS Proxy](https://github.com/Flowseal/tg-ws-proxy). Помогает запускать обход ограничений для YouTube, Discord и других сервисов, а также использовать MTProto-прокси для Telegram Desktop без отдельного окна и второго значка в трее.

## Возможности

- Запуск и остановка выбранной стратегии zapret.
- Отдельный запуск Telegram-прокси или совместный запуск кнопкой **«Запустить всё»**.
- Полностью интегрированный фоновый движок TG WS Proxy: управление, настройка порта, журнал и подключение находятся в Zapret Control.
- Автозапуск Telegram-прокси при входе в Windows через скрытый Zapret Control в трее.
- Подключение Telegram Desktop через готовую `tg://proxy` ссылку.
- Сохранение секрета прокси и расширенной конфигурации между запусками и обновлениями.
- Пользовательские списки доменов, IP-адресов и исключений.
- Настройка игрового фильтра и IPSet.
- Проверка доступности YouTube и Discord и встроенная диагностика.
- Автоматическая проверка релизов приложения, ядра и прокси каждые 6 часов.
- Необязательная автоматическая установка обновлений с обязательной проверкой SHA-256.
- Обновление самого Zapret Control с автоматическим перезапуском и сохранением всех пользовательских файлов.
- Сохранение пользовательских списков, настроек и секрета прокси при обновлении.
- Сворачивание Zapret Control в системный трей при закрытии окна. В меню значка доступны запуск/остановка компонентов, подключение Telegram и полный выход.

## Требования

- Windows 10 или Windows 11 x64.
- Права администратора для запуска zapret и управления системной службой.
- Telegram Desktop для использования MTProto-прокси.

## Установка и запуск

1. Скачайте `ZapretControl-win-x64.zip` со страницы [Releases](../../releases/latest).
2. Полностью распакуйте архив в отдельную папку. Не запускайте приложение внутри ZIP.
3. Запустите `ZapretControl.exe` и разрешите запуск от имени администратора.
4. Нажмите **«Запустить всё»** или включите обход и Telegram-прокси по отдельности.
5. Для Telegram после запуска прокси нажмите **«Подключить Telegram»** и подтвердите добавление прокси в Telegram Desktop.

При первом включении скачивается интегрированный движок TG WS Proxy. Он собирается в GitHub Actions из официального исходного кода Flowseal с отдельным фоновым entrypoint без tray-оболочки. Загруженный файл проверяется по SHA-256, предоставленному GitHub.

Порт прокси изменяется в настройках Zapret Control. При сохранении запущенный прокси автоматически перезапускается. Там же включается автозапуск прокси при входе в Windows; используется задача планировщика с высокими правами, поэтому UAC при входе не появляется.

При обновлении и переносе приложения в другую папку предыдущие копии `TgWsProxy.exe` автоматически завершаются перед запуском нового прокси. Запуск или остановка обхода также завершает старые процессы `winws.exe`, включая процессы из прежних каталогов установки. Если порт занят другой программой, приложение показывает понятное сообщение и предлагает изменить порт.

### Закрытие и трей

Крестик в окне и `Alt+F4` скрывают Zapret Control в системный трей, не останавливая запущенные компоненты. TG WS Proxy не создаёт собственный значок. Чтобы восстановить окно, дважды нажмите на значок Zapret Control или выберите **«Открыть Zapret Control»**. В контекстном меню также доступны **«Запустить всё»/«Остановить всё»**, отдельные переключатели компонентов и подключение Telegram. Для завершения интерфейса выберите **«Закрыть полностью»**.

## Обновления

На странице **«Обновления»** можно отдельно проверить и установить новые версии Zapret Control, ядра zapret и TG WS Proxy. Автоматическая проверка и автоустановка включаются и выключаются переключателями; изменения сохраняются сразу.

При обновлении приложения скачивается ZIP-релиз и проверяется SHA-256, предоставленный GitHub. Извлекается только новый `ZapretControl.exe`, после чего отдельный updater заменяет его и перезапускает приложение. Ядро, списки, настройки и данные прокси не перезаписываются.

Ядро zapret загружается из официального репозитория Flowseal. Для прокси приложение проверяет последний официальный релиз `Flowseal/tg-ws-proxy`, а затем скачивает соответствующий фоновый движок из `invayt61/ZapretControl`. Workflow `.github/workflows/build-tg-ws-proxy.yml` ежедневно проверяет первоисточник и автоматически публикует сборку новой версии. Обновление отменяется, если SHA-256 отсутствует или не совпал.

## Сборка

Нужен [.NET 6 SDK](https://dotnet.microsoft.com/download/dotnet/6.0) с поддержкой рабочей нагрузки Windows Desktop.

```powershell
cd Windows
dotnet build ZapretControl.csproj -c Release
./build.ps1
```

Готовые файлы создаются в `Windows/ZapretControl`, а архив — `Windows/ZapretControl-win-x64.zip`.

Фоновый движок Telegram собирается отдельно в GitHub Actions. Файлы `integration/TgWsProxyHeadless.py` и `integration/TgWsProxyHeadless.spec` подключают CLI-движок официального проекта без GUI и трея.

### Проверки

```powershell
dotnet bin/Release/net6.0-windows/ZapretControl.dll --self-test
dotnet bin/Release/net6.0-windows/ZapretControl.dll --verify-update
dotnet bin/Release/net6.0-windows/ZapretControl.dll --verify-ui
dotnet bin/Release/net6.0-windows/ZapretControl.dll --verify-tray
```

- `--self-test` проверяет стратегии и доступность метаданных релизов.
- `--verify-update` дополнительно скачивает релизы во временную папку, проверяет установку и запускает Telegram-прокси на тестовом локальном порту.
- `--verify-ui` создаёт снимки страниц во временной папке для визуальной проверки.
- `--verify-tray` проверяет скрытие, восстановление и полный выход.

## Структура

- `Windows/Services` — запуск процессов, настройки, обновления и диагностика.
- `Windows/ViewModels` — команды и состояние интерфейса.
- `Windows/Models` — настройки и модели данных.
- `Windows/engine` — ядро `zapret-discord-youtube`, стратегии и списки.
- `Windows/Assets` — иконка приложения.
- `integration` — фоновый entrypoint и PyInstaller-спецификация TG WS Proxy.
- `.github/workflows` — автоматическая сборка движка из новых релизов первоисточника.

## Первоисточники и лицензии

Проект является независимым неофициальным интерфейсом и не связан с Flowseal или Telegram. Основная работа по обходу и MTProto-прокси выполняется сторонними проектами:

- [Flowseal/zapret-discord-youtube](https://github.com/Flowseal/zapret-discord-youtube) — ядро и стратегии zapret.
- [Flowseal/tg-ws-proxy](https://github.com/Flowseal/tg-ws-proxy) — исходный код локального MTProto-прокси для Telegram Desktop.
- [bol-van/zapret](https://github.com/bol-van/zapret) — исходный проект zapret.
- [basil00/WinDivert](https://github.com/basil00/WinDivert) — драйвер перехвата пакетов.

Подробности и лицензионные уведомления находятся в [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md) и `Windows/engine/LICENSE.txt`.
